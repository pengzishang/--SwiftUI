## 版本目录说明

- `v1.0/`：日报阅读基础闭环，包含首页、详情、历史加载、分享、缓存和验收证据。
- `v1.1/`：轻量个人能力，包含阅读管理、设置、性能优化、启动屏和体验打磨。
- `v1.2/`：当前主线，包含网络库 Alamofire 重构、知乎热榜功能引入、已读/收藏合并为“我的”页面及自定义胶囊平滑滑动切换栏。
