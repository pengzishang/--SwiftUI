# 《日报阅读器》产品需求文档 v1.2

## 0. 文档信息

| 项目 | 内容 |
| --- | --- |
| 产品名称 | 日报阅读器 |
| 产品版本 | v1.2 |
| 目标平台 | iOS 17+ |
| 技术方向 | SwiftUI + WebKit + Alamofire |
| 数据源 | 知乎日报接口 `https://news-at.zhihu.com/api/4` & 知乎热榜接口 `https://www.zhihu.com/api/v3` |
| 当前定位 | 学习作品集，不代表知乎官方产品 |

## 1. 版本目标

v1.2 主要聚焦于**网络层重构**、**知乎热榜功能引入**以及**个人数据整合与导航优化**。
核心目标包括：
1. **网络底层迁移**：网络模块改用行业标准异步库 **Alamofire** 进行底层 HTTP 请求管理。
2. **热榜浏览**：新增独立“热榜” Tab，支持展示知乎实时热门问题 Top 50，并能点击查看回答预览及阅读完整回答正文。
3. **“我的”个人页面重构**：将原“收藏” Tab 和“已读” Tab 合并为一个统一的“我的” Tab。顶部采用自定义的**药丸胶囊背景滑动切换栏**进行平滑无缝切换，提高空间利用率并优化视觉质感。
4. **统一搜索**：在“我的”页面提供单搜索框，自动根据当前激活的子 Tab（收藏 / 已读）实时过滤对应列表数据。

## 3. 功能范围

### 3.1 网络底层迁移 (Alamofire Migration)

- 底层网络调用类 `HTTPClient` 改用 **Alamofire** (基于 Swift Concurrency `async/await` 接口)。
- 在请求头中配置统一的浏览器 `User-Agent`，解决非日报接口的防爬与鉴权拦截问题。
- 保持原有的错误转换逻辑（转换至 `APIError`）。

### 3.2 热榜与回答详情 (Hot List & Answers)

- **热榜列表 (HotListView)**：
  - **接口**：`GET https://www.zhihu.com/api/v3/feed/topstory/hot-lists/total?limit=50`
  - **展示规则**：
    - 左侧显示排行数字。第 1、2、3 名数字分别采用红色、橙色、黄色进行特殊高亮，其余名次显示为深灰色。
    - 右侧显示热点问题的标题，以及底部的热度数据（例如 `52.4M 热度`）。
  - **分页与刷新**：不支持分页加载更多，仅固定展示前 50 条热榜数据。支持下拉刷新和加载失败时展示“加载失败”提示与“重试”按钮（不提供 Mock fallback 离线数据）。
- **回答列表页 (QuestionAnswersView)**：
  - **接口**：`GET https://www.zhihu.com/api/v4/questions/{id}/answers?include=content,excerpt,voteup_count,comment_count,author&limit=20`
  - **展示规则**：顶部显示问题完整标题。列表包含前 20 条精选回答预览，单项展示作者圆形头像、作者昵称、回答摘要、点赞赞同数。
  - **分页与刷新**：仅固定加载前 20 条精选回答，不支持加载下一页，仅支持下拉刷新。
- **回答详情页 (AnswerDetailView)**：
  - **渲染规则**：点击单条回答预览后，推入独立的详情视图。使用现有的 `HTMLWebView` 对回答的完整 HTML 正文进行全宽渲染，保持加粗、排版、大图呈现，适配系统 Dynamic Type 缩放。

### 3.3 “我的”个人页面重构 (Consolidated Profile View)

- **导航合并**：
  - 底部 TabBar 由原先的 5 Tab（日报、收藏、已读、设置，冷宫在设置中）合并重构为 4 Tab：
    1. **日报** (HomeView)
    2. **热榜** (HotListView)
    3. **我的** (MeView)
    4. **设置** (SettingsView)
- **药丸胶囊滑块切换栏**：
  - 在“我的”页面顶部设计水平切换栏，包含“收藏”与“已读”两个选项。
  - 使用 SwiftUI 原生 `@Namespace` 共享命名空间和 `.matchedGeometryEffect` 实现药丸形半透明胶囊背景在两个选项后的平滑移动效。
- **极简无头像布局**：
  - 页面顶部采用大导航标题“我的”，直接衔接胶囊切换栏，不保留任何虚拟的个人头像、名称或已读/收藏数量统计，保持界面极简和直观。
- **统一搜索**：
  - 切换栏正下方提供一个输入搜索框。当用户处于“收藏”视图时，过滤搜索收藏的内容；当处于“已读”视图时，过滤已读历史的列表内容。
- **列表交互**：
  - 继承 v1.1 已实现的侧滑交互：收藏列表左滑“取消收藏”，已读历史左滑“设为未读”。

## 4. 交付与验收标准

1. **编译运行**：
   - 依赖集成正确，`xcodebuild` 命令行编译无错误。
2. **测试要求**：
   - Alamofire 网络层请求可平稳返回数据，网络超时与网络阻断时能触发标准错误重试页面。
   - 热榜列表、回答列表、回答正文 WebView 呈现完美，长文本滑动不卡顿。
   - “我的”页面滑动或点击切换子 Tab，胶囊动画过渡自然，无瞬间闪烁或移位，且搜索过滤在两个子列表中皆生效。
