# 双正文系统交付概览

## 已完成

- 将文章详情页正式划分为问答式与文章式两套模板。
- 问答式沿用连续 WebView 方案，使用普通滚动导航标题。
- 文章式采用「墨迹岛」：滚动后出现标题胶囊与朱砂阅读进度，点击展开完整标题和作者。
- 两套模板共享单一 WKWebView 架构、纸面压印按钮、操作菜单、头像规则、图片查看器、安全链接和阅读位置能力。
- 输出双模板同屏交互原型和完整实施计划。

## 关键决策

- 模板优先由显式字段决定；无字段时才使用 DOM 结构识别。
- 问答式不使用墨迹岛，避免信息密度过高。
- 文章式题图可选；无题图时折叠媒体空间。
- 有头像保留，无头像折叠；不在原生层重复文章内容。

## 后续
