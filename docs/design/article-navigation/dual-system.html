A · 问答式「问答长卷」

适合瞎扯、合集和多回答内容。强调问题—回答—图片的连续节奏，导航滚动后显示普通标题副本。

问答式规则

导航

正文标题自然滚走后，中央显示普通 16pt 宋体标题副本；不使用进度胶囊，避免问答合集本已较高的信息密度继续增加。

正文

  • 问题标题 20pt 宋体，段前 30pt。
  • 回答用 2pt 淡墨竖线与 15pt 左缩进。
  • 回答头像有效则保留 26pt，无头像则折叠。
  • 多图保持 HTML 顺序，连续图片间 14pt。

按钮

导航按钮、关注、讨论入口和操作菜单全部使用“纸面压印”：44pt 热区、靛蓝交互色、按下 scale .92–.96。

类型识别 · 结构证据链

第一层 · 显式字段详情或列表提供 qa / article / fallback 时直接锁定，置信度 1.0。
第二层 · 强 DOM优先识别 data-question-id、Question/Answer itemtype、question/answer 类名等语义节点。
第三层 · 真实序列识别至少两组「Q：可点击问题 → @回答者 → 相邻回答块/竖线」；这是本次运行截图揭示的关键补充。
冲突与低置信度任何证据不足或文章段落信号冲突时进入 fallback；一次文档生命周期只决策一次。

标题含“瞎扯”只作为诊断弱信号，不参与单独定案，避免普通文章标题或引用文字造成误判。

文章式「墨迹岛」规则

开篇

27pt 宋体标题 → 18pt → 38pt 作者署名 → 22pt → 可选题图。无题图时文武线直接接正文，不预留媒体高度。

墨迹岛

  • 标题底边离开视口后出现，36pt 高，最大宽 220pt。
  • 左侧 4pt 朱砂纵向刻度显示阅读进度。
  • 点击展开完整标题、24pt 作者头像、作者名和百分比。
  • 不使用自动跑马灯；AX 大字号显示“文章标题”，点击查看全文。

动效

进入 220ms expo-out，退出 165ms ease-in；快速滚动只更新进度刻度。Reduce Motion 保留显隐和进度语义，取消空间位移。

共享设计基础

纸面压印按钮导航、菜单、关注、讨论入口共用状态与按压反馈。
单一 WKWebView两种正文都由一个滚动容器承载，不测量并嵌套外层 ScrollView。
媒体与链接桥图片全屏查看；站内路由；外链安全浏览器；未知 scheme 拒绝。
头像条件渲染有效头像保留；失败显示首字；无作者时折叠头像槽。
阅读能力位置恢复、进度、返回顶部都直接绑定 WebView scrollView。
深浅色与字号动态 CSS token；正文缩放至 200%；Reduce Motion 降级。
操作菜单分享、收藏、已读、不感兴趣；收藏乐观更新，危险操作可撤销。
无内容降级无作者、无题图、无图注时折叠对应空间，不展示空容器。

总实施路线

PHASE 1滚动架构

让 WKWebView 成为唯一滚动容器；迁移进度、位置恢复和返回顶部。

PHASE 2模板识别

建立 qa / article / fallback 三类内容模板和稳定识别规则。

PHASE 3DOM 与样式

统一按钮、作者、问答、图片、链接、引用和墨迹岛消息桥。

PHASE 4测试与迁移

Fixtures、快照、UI 测试和真实文章抽样；灰度替换旧详情页。

交互：分别滚动两台手机；点击文章式墨迹岛查看完整标题；两侧右上按钮共享操作菜单；可切换头像状态和深浅色。
