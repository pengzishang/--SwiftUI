DAILYREADER · 文章导航重构

让标题从“被挤压的标签”回到“阅读的上下文”

三个方案均延续「今日刊」的暖纸、浓墨、宋体与髮丝线语言。拖动阅读进度可查看导航状态变化；点击紧凑标题可查看完整标题。

一、题随文隐

沉浸式大标题 + 滚动折叠导航
4 行正文标题上限
64 pt进入折叠区
220 ms状态过渡

设计思路与页面结构

正文里的 26pt 宋体标题承担完整表达，导航栏初始只保留返回和操作。标题顶端越过导航栏后，中央出现单行上下文标题；用户不需要同时阅读两个标题。

静态与动态

  • 0–24pt：透明语义，中央留白，突出封面与文章题花。
  • 24–64pt：正文标题以裁切与透明度退出；导航标题同步淡入。
  • ≥64pt：导航栏纸色稳定、露出髮丝线，标题单行省略。
  • 点击紧凑标题：出现完整标题 popover；反向滚动到 32pt 以下恢复初始态，形成迟滞区避免闪烁。

响应式与可访问性

320–375pt 保持操作按钮 44pt，导航标题只承担定位，不强求视觉完整；完整标题始终在正文和辅助功能标签中。动态字号 ≥AX3 时导航标题改为“文章”并以点击展开全文标题，避免伪多行挤压。

优势与成本

优势：最沉浸、最接近现有结构、改动最小。
风险：滚动后视觉标题仍可能省略，但完整信息有明确入口。
实施：低—中；复用现有 ArticleScrollObserver，将 offset 映射到 toolbar principal。

二、双层报眉

操作层固定 + 标题层自适应
2 行吸顶标题上限
94 pt展开总高度
240 ms折叠过渡

设计思路与页面结构

把横向竞争改成纵向分层：第一层只放返回与操作，第二层用完整宽度显示两行宋体标题，像报纸报眉。正文的大标题在该方案中可缩为 22pt 或在短标题时省略，减少重复。

静态与动态

  • 初始：50pt 操作层 + 最多两行标题层，底部髮丝线。
  • 滚动 0–88pt：标题层用向上位移与 clip 收起，不直接动画高度。
  • ≥88pt：只保留操作层，中央显示“文章”或来源短标签。
  • 轻点操作层中央：标题层临时展开；滚动恢复后自动收起。

响应式与可访问性

小屏维持 16pt/21pt 两行；390pt 以上为 17pt/22pt；iPad 分栏可显示三行但总高不超过 112pt。AX 大字号下标题层随内容增高，不和按钮同排，信息完整性最佳。

优势与成本

优势：完整性、大字号与中英混排最稳，操作永不受标题挤压。
风险：首屏纵向占用增加，若正文仍保留完整大标题会重复。
实施：中；需要自定义 safeAreaInset 顶栏并谨慎处理系统返回手势。

三、墨迹岛

标题胶囊 + 阅读进度联动
34 pt紧凑胶囊高度
12%显示阈值
200 ms展开反馈

设计思路与页面结构

初始让完整标题留在正文；滚动超过文章头部后，中央出现独立纸面胶囊。左侧 4pt 朱砂刻度显示阅读进度，标题负责定位，操作菜单仍位于右侧。

静态与动态

  • <12%：导航中央留白；进入正文后胶囊淡入并上移 6pt。
  • 标题默认单行渐隐，不自动跑马灯，避免持续运动干扰阅读。
  • 点击胶囊：在导航下展开完整标题、来源与进度；再次点击或继续滚动收起。
  • 快速滚动只更新进度刻度，不重复播放进入动画。

响应式与可访问性

320pt 下胶囊最大宽度 168pt；430pt 为 238pt；横屏与 iPad 最大 320pt。AX 大字号时胶囊语义改为图标 + “标题”，展开面板显示可换行全文。进度同时提供 VoiceOver 百分比，不仅依赖颜色。

优势与成本

优势：辨识度最高，把现有阅读进度能力转化为品牌化导航。
风险：信息密度较高，胶囊可能被误解为按钮；需要首次使用可发现性。
实施：中—高；需要自定义 principal、展开面板、进度状态和更多 UI 测试。

先选方案一，再借用方案三的“点击查看全文”

它最符合内容阅读习惯：完整标题只在进入文章时强表达，阅读中导航仅提供上下文；同时能直接复用现有完整正文标题与滚动监听，风险最低。MVP 只需实现三态导航、64pt 折叠阈值、完整标题弹层、动态字号与 Reduce Motion 降级，并覆盖 320pt / 390pt / iPad 分栏三组快照。

交互说明：拖动阅读进度；切换方案、字号和深浅色；点击紧凑标题展开完整信息。所有按钮保持至少 44 × 44pt。
