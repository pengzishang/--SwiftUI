# 文章正文与导航 V3 交付概览

## 已完成

- 根据实际截图重新审查页面，确认它属于问答合集型连续正文，而不是固定封面文章。
- 将方案重构为“原生导航 + 单一可滚动 WKWebView”。
- 标题、作者、链接、问答、引用、图片、图注和讨论入口全部进入同一 Web 内容流。
- 设计了真实头像保留、无头像槽折叠、头像失败首字降级三种状态。
- 修正图片与标题距离、连续图片间距和图注节奏。
- 新增正文图片点击、内联链接点击、标题自然滚动交接、字号和深浅色演示。
- 补充了 WebView CSS、DOM 结构、图片/链接桥接与三种正文类型验证规则。

## 关键决策

- 不再在原生层固定渲染 `detailImageURL`，避免与 HTML 正文图片重复。
- 不通过 opacity/transform 搬走正文标题；标题自然滚出，导航显示同步副本，因此不会留下布局空白。
- 有有效头像就保留；没有头像时折叠整个头像槽，不强制占位。
- 建议让 WKWebView 成为唯一滚动容器，移除外层 ScrollView 和 `max(height, 520)` 动态高度方案。

## 后续建议

优先重构滚动架构，再统一 HTML CSS。先使用问答合集、编辑文章、无作者无图片三类 fixture 做关键路径验证，之后再完善图片长按和站内链接路由。
