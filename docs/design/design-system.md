# DailyReader 设计系统 ——「今日刊」

## 1. 气质与身份

DailyReader 是一份**每天一期的刊物**，而不只是一个信息流应用。设计语言取自中文报刊传统：暖纸作底、浓墨为字、宋体承担版面结构，靛蓝如蓝黑墨水作全局强调，朱砂只在「今日」印章与热榜首位等极少数地方点睛。

**签名元素：日期刊头。** 每一天的内容以一条报纸式日期栏开场——朱砂「今日」章记 + 宋体中文日期（如「七月二十六日」）+ 星期 + 篇数，下压一道报眉惯用的**文武线**（一粗一细双线）。次级签名是热榜的宋体特粗大号排名数字。

实现载体：`DailyReader/Shared/UI/Theme.swift`（`DS` 命名空间 + `ChineseDate` 工具 + `DatelineHeader` / `SealChip` / `RuleLine` 组件）。

## 2. 色彩

### 色板（全部为深浅色自适应动态色）

| 角色 | 令牌 | 浅色 | 深色 | 用途 |
|------|------|------|------|------|
| 纸底 | `DS.paper` | `#F9F6EF` | `#141311` | 所有页面背景、导航栏、标签栏 |
| 纸面浮层 | `DS.paperElevated` | `#FFFEFA` | `#1F1D19` | 卡片、输入框、分组行、占位图 |
| 浓墨 | `DS.ink` | `#26221B` | `#E8E3D8` | 标题、正文、选中态 |
| 淡墨 | `DS.inkSecondary` | `#706B5E` | `#A29C8C` | 辅助文字、已读态、未选中态 |
| 靛蓝 | `DS.indigo` | `#2C4A7C` | `#94ADDA` | 全局 tint：链接、按钮、滑杆、恢复操作 |
| 朱砂 | `DS.cinnabar` | `#B73729` | `#E06C58` | 「今日」印章、热榜第一、不感兴趣、离线横幅 |
| 赭石 | `DS.ochre` | `#B06924` | `#D89956` | 热榜第二、设为未读 |
| 藤黄 | `DS.gold` | `#967A1D` | `#CAB25C` | 热榜第三（印刷可读的暗金，避免纯黄失色） |
| 髮丝线 | `DS.hairline` | 墨 14% | 浅墨 16% | 分隔线、描边 |

### 规则

- 页面一律铺纸底；列表用 `.listStyle(.plain)` + `paperListBackground()`，行背景透明。
- 靛蓝是唯一的交互强调色（App 根部 `.tint(DS.indigo)`）；朱砂/赭石/藤黄只作语义点睛，不作交互色。
- 热榜前三名保持"红/橙/黄"的语义（v1.2 需求 R2），但取印刷调的朱砂/赭石/藤黄。
- 空态与报错用淡墨文字置于纸底之上，不再使用系统分组灰。

## 3. 字体

### 层级

| 层级 | 字体 | 字号 | 用途 |
|------|------|------|------|
| 刊头 | 宋体特粗 `STSongti-SC-Black` | 31pt | 导航大标题（日报首页） |
| 详情标题 | 宋体特粗 | 26pt | 文章详情页大标题 |
| 热榜数字 | 宋体特粗 | 23 / 19pt | 前三名 23pt 彩色，其余 19pt 淡墨 |
| 日期刊头 | 宋体加粗 `STSongti-SC-Bold` | 19pt | 分节日期栏 |
| 列表标题 | 宋体加粗 | 列表字号 + 1 | 故事行、热榜条目、问题标题 |
| 导航标题 | 宋体加粗 | 17pt | 内页导航栏 |
| 正文/辅助 | 系统黑体 | 12–16pt | 摘要、热度、说明文字 |

### 规则

- 宋体只用于**结构性文字**（刊头、标题、日期、大数字），正文与密集信息一律系统黑体，保证可读性。
- 宋体经由 iOS 内置 Songti SC 加载（`DS.songBold(_:)` / `DS.songBlack(_:)`），无需打包字体文件。
- 已读态由浓墨降为淡墨、缩略图降不透明度，不缩小字号。
- 列表与正文字号仍随设置页滑杆（14–22pt）缩放。

## 4. 间距与版式

### 基准

间距仍以 4pt 为基准单位。

| 令牌 | 值 | 用途 |
|------|-----|------|
| space-1 | 4pt | 胶囊内衬 |
| space-2 | 8pt | 行内文字节奏、题下信息行 |
| space-3 | 12–14pt | 行横向间隙 |
| space-4 | 16pt | 页面边距、空态间距 |
| 刊头上衬 | 14pt | DatelineHeader 顶部 |

### 版式

- 列表行媒体保持固定尺寸（72pt 方图、240×132 顶部卡片）防止列表跳动。
- 圆角整体收敛（图 9–12pt、卡片 14pt、胶囊除外），配 0.7pt 髮丝线描边，取印刷图版感。
- 分节头吸顶时自带纸底，不透内容。

## 5. 组件

### 日期刊头 DatelineHeader（签名组件）

- **结构**：`[今日印章?] 宋体中文日期 星期 …… N 篇`，下压文武线（1.4pt 墨线 + 0.6pt 髮丝线）。
- **规则**：仅当日显示朱砂 `SealChip("今日")`；跨年日期自动带「二〇二五年」前缀；非 8 位日期字符串原样展示。
- **使用处**：日报首页、我的-收藏、冷宫的所有分节。

### 印章 SealChip

- 朱砂底白字小方章，3pt 小圆角保留「盖印」感；宋体 11pt。

### 故事行 StoryRowView

- **结构**：宋体标题（≤3 行）+ 黑体摘要，尾随 72pt 缩略图（9pt 圆角 + 髮丝线描边）。
- **状态**：未读浓墨；已读淡墨 + 图片 62% 不透明度。

### 热榜行

- **结构**：宋体特粗排名数字（宽 34pt 居中）+ 宋体标题 + 热度小字 + 髮丝线描边缩略图。
- **状态**：前三名朱砂/赭石/藤黄 23pt，其余淡墨 19pt；已读标题降淡墨。

### 占位图 PlaceholderImageView

- 纸面浮层底 + 宋体「日」字水印（淡墨 38%），加载失败与加载中共用。

### 离线横幅 OfflineBanner

- 朱砂 8% 纸面底、朱砂 28% 髮丝线描边、朱砂图标 + 浓墨文字。

### 胶囊滑块（我的页）

- 纸面浮层轨道 + 髮丝线描边；选中块为**墨块**，文字反白如铅字压印；`matchedGeometryEffect` 弹簧动效保持不变。

## 6. 动效与交互

| 类型 | 时长 | 缓动 | 用途 |
|------|------|------|------|
| 原生 | 系统 | 系统 | 导航、标签、下拉刷新、滑动操作 |
| 胶囊滑块 | 0.3s | spring(0.8) | 我的页子 Tab 切换 |

- 阅读流不加装饰性动画。
- 滑动操作按语义着色：不感兴趣=朱砂、设为未读=赭石、恢复=靛蓝、取消收藏=淡墨。

## 7. 深浅与层次

| 层级 | 值 | 用途 |
|------|-----|------|
| 纸底 | `DS.paper` | 一切页面 |
| 纸面浮层 | `DS.paperElevated` | 卡片、输入框、分组行 |
| 髮丝线 | `DS.hairline` | 分隔与描边，代替阴影 |

- **不用阴影表达层次**，用髮丝线与浮层纸色；深色模式是「夜里的墨纸」而非纯黑。
- 导航栏/标签栏为不透明纸色（`DS.applyGlobalAppearance()`），滚动后导航栏露出髮丝线。
- 正文 WebView 注入同源墨色/靛蓝/淡墨（随深浅色即时解析并重载）。
- 文章作者信息采用“报刊署名栏”：42pt 圆形头像、宋体作者名与黑体简介融合为单一横排模块，上下以髮丝线收束，不使用孤立胶囊卡片。
- 正文首段使用宋体首字下沉，约 3.35 倍正文字号，承担杂志开篇的视觉锚点。
- 正文向下滚动超过 200pt 后，右下角显示 54pt 回顶按钮；靛蓝圆环与百分比随滚动同步表达阅读进度，点击后平滑返回顶部并自动隐藏，按钮触控区域不低于 44pt，并提供完整辅助功能标签。

## 8. 启动屏

- 背景 `LaunchBackground`：纸底（浅 `#F9F6EF` / 深 `#141311`）。
- 品牌图 `LaunchBrandMark`：白卡靛蓝字形 + 墨色标语（深色模式为墨卡浅靛字形 + 浅墨标语），与 App 内视觉同源。
