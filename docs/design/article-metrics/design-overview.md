# 文章互动数据设计概览

## 已完成

- 完成首页文章 Cell 与文章正文头部的互动数据 UI 设计及 SwiftUI 试做实现。
- 以真实运行界面为基线，保留现有列表 Cell、72pt 缩略图、详情标题/来源/日期和 `RuleLine()`，仅增补题下指标信息。
- 产出可交互 HTML 预览、实施规范，以及首页/详情/无数据状态的模拟器运行截图。
- 实现异步加载、无数据隐藏、不落盘缓存、日报/原回答数据源分离、唯一原回答映射与 VoiceOver 语义。

## 关键决策

- 首页仅显示知乎日报“热度”和“评论”，避免逐 Cell 请求原回答数据。
- 正文将“日报数据”和“原回答”分行展示，禁止混淆 `popularity` 与原回答赞同数。
- 浏览量、分享次数暂不展示；无可靠同语义数据源。
- 加载中不显示骨架或转圈；成功后克制淡入；失败或为空时整组隐藏。
- 不落盘、不跨页面缓存；允许单个页面生命周期内合并重复并发请求。
