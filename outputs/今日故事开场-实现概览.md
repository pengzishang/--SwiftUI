# 今日故事开场｜实现概览

## 已实现

- 新增 `TodayStoryOpeningView`，仅展示第一条 `topStories` 的“今日故事”标签、题图与标题。
- 在首页离线横幅之后、首个日期分节之前接入开场组件。
- 整块使用现有 `NavigationLink` 进入 `ArticleDetailView`，没有新增中间页面或业务能力。
- 复用现有 `PlaceholderImageView` / `RemoteImageView` 与 Kingfisher 图片链路；无图或加载失败时保留纸面占位、标题和导航。
- 三档首页密度共用同一组件，仅调整高度、圆角、内边距与标题行数。
- 支持动态字体、辅助功能大字号、VoiceOver 标签与稳定 UI 测试标识。

## 测试与验证

- `TodayStoryOpeningTests`：顶部故事到 `StorySummary` 的字段映射、无图导航、首条选择规则。
- `HomeInformationDensityTests`：三档开场高度、圆角和标题行数。
- `HomeFlowUITests`：开场出现并进入现有详情、日报有内容但顶部故事为空时不显示开场。
- `latest_without_top_stories` 本地 Fixture 场景。

已通过：

- 相关 Swift 文件语法解析；
- XcodeGen 配置校验；
- `.xcodeproj` 结构校验；
- `git diff --check`；
- 越界功能关键词扫描；
- 真实编译与单元测试：使用 SwiftPM 无嵌套沙箱参数（`SWIFTPM_DISABLE_SANDBOX=1` 等）在 iOS 模拟器完成 App、单元测试包和 UI 测试包的编译、签名与执行。`DailyReaderTests` 共 38 个测试，36 个通过；本功能相关测试（`TodayStoryOpeningTests` 3 个、`HomeInformationDensityTests`）全部通过。

Xcode 27 Beta 环境下的既有失败（与本功能无关，未在本需求内修复）：

- `KeychainDataStoreTests.testMultipleLegacyCandidatesAreRejectedWithoutDeletion`：测试 mock 未设置 `legacyData`（默认 `nil`），`copyMatching` 提前返回 `errSecItemNotFound`，`legacyCandidateCount = 2` 分支永远无法触发，断言“期望抛错”必然失败。属于 `zhihu-login` 功能的既有测试缺陷。
- `OAuthConfigurationTests.testHTTPAuthorizationEndpointIsRejected`：断言失败时触发 XCTest 框架级崩溃（`XCTFailableInvocation`），单独运行该用例也会使测试进程崩溃并等待超时。属于 Xcode 27 Beta 测试框架问题。
