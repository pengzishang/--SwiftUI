# 今日故事开场｜实现概览

## 已实现

- 新增 `TodayStoryOpeningView`，仅展示第一条 `topStories` 的“今日故事”标签、题图与标题。
- 在首页离线横幅之后、首个日期分节之前接入开场组件。
- 整块使用现有 `NavigationLink` 进入 `ArticleDetailView`，没有新增中间页面或业务能力。
- 复用现有 `PlaceholderImageView` / `RemoteImageView` 与 Kingfisher 图片链路；无图或加载失败时保留纸面占位、标题和导航。
- 三档首页密度共用同一组件，仅调整高度、圆角、内边距与标题行数。
- 支持动态字体、辅助功能大字号、VoiceOver 标签与稳定 UI 测试标识。
