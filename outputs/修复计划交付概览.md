## 关键决策

- AI 会话持久化在 actor 内使用单调 revision，确保旧快照不能覆盖新状态。
- 首页 Feed 通过 stream termination 取消 producer，并在缓存副作用前后保持取消语义。
- Keychain 统一为 service + account、throwing API 和“复制—验证—精确删除”的兼容迁移。
- HTTPClient 每个请求创建独立 JSONDecoder。
- OAuth 源码和测试纳入默认 targets，但普通运行固定 unavailable；仅显式 UI 测试模式使用 fixture，不启用真实生产登录。
