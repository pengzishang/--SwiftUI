# 编译问题修复概览

- 分支：`fix/compile-errors-20260803`
- 提交：`af17790 fix: 修复首页状态初始化编译错误`

## 根因

`HomeViewModel.init` 在 `readStoryIDs`、`hiddenStories`、`favoriteStories`、`readStories` 尚未完成初始化时，调用了实例方法 `readBackup`、`saveBackup` 和 `deleteBackup`。这些方法隐式使用 `self`，违反 Swift 的两阶段初始化规则。

已有 Xcode 编译日志中的核心错误为：

```text
HomeViewModel.swift: error: 'self' used in method call 'readBackup' before all stored properties are initialized
```

## 修复

- 初始化阶段改用局部闭包，直接操作注入的 `ReadingStateBackingUp` 和错误处理器，不再提前访问 `self`。
- 初始化阶段使用局部持久化 key，避免通过实例属性访问 `self`。
- 将 `AIConfigurationStore.userProviderID` 和 `defaultProviderID` 标记为 `nonisolated static let`，消除非隔离凭据存储访问主 actor 常量的 Swift 6 升级风险。
- P1-1 非目标配置保持不变。
